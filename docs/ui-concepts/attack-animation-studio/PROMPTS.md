# Image-generation prompt set

Mode: built-in image generation. Use case: `ui-mockup`.

## 01 — Build

Create a high-fidelity, shippable-looking Blender 5 dark-theme screenshot of
the Dreadstone `ATTACK ANIMATION STUDIO` in its Build state. Use a large 3D
viewport, a compact right N-panel, and a shallow animation timeline. In the
viewport show a gray humanoid rig in a one-handed overhead sword pose facing a
translucent red upper-torso target, with a cyan/orange/violet phase trail and a
yellow contact point. The panel uses `BUILD | REVIEW | ADVANCED`, a `CHOOSE`
card for `Attack`, `Weapon`, and `Target`, a `SHAPE` card for Feel, Power,
Windup, Body Motion, Follow-Through, Aim, and Auto Fit Reach, then one wide
`GENERATE & PLAY` action. Preserve authentic Blender proportions, readable
typography, and restrained accents; avoid sci-fi HUD styling and clutter.

## 02 — Review

Using the Build image as the visual-series reference, create the matching
Review state. Freeze the same character at CONTACT with the blade meeting the
target. Show yellow intended contact, magenta baked closest point, a subtle
strike plane, and the same phase trail. Select the `REVIEW` tab. Show a compact
`READY TO APPROVE` banner; a 2×2 Quality grid for Target Contact PASS, Pose
Health PASS, Reach 86%, and Smoothness 18°; Windup/Contact/Recovery inspection
buttons; Target/Trail/Strike Plane toggles; `PLAY ATTACK`; and one dominant
`APPROVE ATTACK` action. Keep the successful state concise and omit the bypass.

## 03 — Advanced recovery

Using the first two images as visual-series references, create the matching
Advanced state for an overextended preview. Show orange editable path controls
and a nearly locked but believable arm. Select `ADVANCED`. At top show `NEEDS
CHANGES · PREVIEW ONLY`, `Arm Reach 99.1% · Limit 98.5%`, a short correction
hint, and one dominant `AUTO FIT & REBUILD` action. Below, use progressive
accordions: Target & Weapon collapsed; Path & Timing open with trajectory and
three phase durations plus `REBUILD FROM CONTROLS`; Body & Reach, Validation,
and Utilities collapsed. End with `BACK TO BUILD`, then a visually isolated
danger action `SAVE WITH FAILED CHECKS…`. Keep the layout authentic to Blender
and avoid a wall of sliders.
